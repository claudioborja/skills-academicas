# Selección de guía y extensión

## Decisión inicial

| Producto o rasgo | Documento de reporte | Complemento necesario |
| --- | --- | --- |
| Protocolo de revisión sistemática | PRISMA-P 2015 | Método de conducción y plan analítico |
| Revisión sistemática nueva | PRISMA 2020 | Método de conducción disciplinar |
| Revisión sistemática actualizada | PRISMA 2020, diagrama de actualización | Vincular revisión previa, nuevos registros e incluidos anteriores |
| Revisión sistemática viva | PRISMA 2020 + PRISMA-LSR | Ciclo de vigilancia, actualización y versionado |
| Resumen de revisión | PRISMA 2020 for Abstracts | Límite de palabras de revista/congreso |
| Reporte detallado de búsqueda | PRISMA-S | Estrategia y evaluación de búsqueda |
| Revisión de alcance | PRISMA-ScR | Método de conducción de scoping review |
| Exactitud diagnóstica | PRISMA 2020 + PRISMA-DTA | Método y riesgo de sesgo para DTA |
| Metaanálisis en red | PRISMA 2020 + PRISMA-NMA | Supuestos de transitividad y consistencia |
| Datos individuales | PRISMA 2020 + PRISMA-IPD | Gobierno y análisis de IPD |
| Daños | PRISMA 2020 + PRISMA-Harms | Captura y definición de eventos adversos |
| Equidad como foco | PRISMA 2020 + PRISMA-Equity | Marco y análisis de equidad |

## Reglas

- Aplicar la guía base y solo las extensiones pertinentes.
- Si una extensión fue publicada antes de PRISMA 2020, usarla junto con PRISMA 2020 y revisar la orientación oficial sobre compatibilidad.
- Una revisión puede requerir más de una extensión, pero cada una debe responder a una característica real del producto.
- No etiquetar una revisión narrativa como sistemática solo por completar una checklist.
- No usar PRISMA-ScR para una revisión sistemática de efectos ni PRISMA 2020 estándar para ocultar que el producto es de alcance.
- Verificar requisitos de la revista: pueden pedir checklist, diagrama, protocolo, estrategias completas y lista de excluidos.

## Preguntas de clasificación

1. ¿El objetivo es responder una pregunta definida o mapear amplitud, conceptos y tipos de evidencia?
2. ¿La revisión es nueva, actualización o viva?
3. ¿Hay metaanálisis? ¿Convencional, en red o con datos individuales?
4. ¿El resultado central es exactitud diagnóstica, daños, equidad u otro dominio con extensión?
5. ¿Se está preparando protocolo, resumen, informe completo o actualización?
6. ¿Qué guía gobierna la conducción y qué guía gobierna el reporte?

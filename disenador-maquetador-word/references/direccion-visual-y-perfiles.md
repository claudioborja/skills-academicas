# Dirección visual y perfiles para libros en Word

Leer este documento cuando el proyecto no tenga una plantilla aprobada, cuando la existente deba reconstruirse o cuando el usuario solicite una nueva identidad visual.

## Ficha mínima de diseño

Registrar las decisiones que gobiernan la maqueta:

| Campo | Decisión |
| --- | --- |
| Producto | Género, propósito y extensión aproximada |
| Lector | Especialización, edad, contexto y condiciones de lectura |
| Uso | Edición continua, impresión, distribución digital o combinación |
| Formato | Tamaño de página, orientación, márgenes y encuadernación prevista |
| Voz visual | Sobria, técnica, divulgativa, humanística, didáctica u otra |
| Tipografía | Familias, funciones, licencias, disponibilidad y sustituciones |
| Color | Paleta funcional y comportamiento en escala de grises |
| Recursos | Tablas, figuras, ecuaciones, código, recuadros y notas |
| Navegación | Índice, partes, capítulos, encabezados, folios y referencias cruzadas |
| Restricciones | Plantilla, institución, editorial, accesibilidad y compatibilidad |

Una preferencia no confirmada debe quedar identificada como supuesto modificable, no como requisito del usuario.

## Perfiles de partida

Los perfiles orientan decisiones; no son plantillas rígidas.

### Académico sobrio

- Contraste tipográfico moderado y jerarquía explícita.
- Ornamentación mínima y color limitado a funciones de navegación.
- Tablas, figuras, ecuaciones, notas y bibliografía integradas con disciplina.
- Prioridad a legibilidad, citas y revisión institucional.

### Divulgación científica

- Aperturas claras, subtítulos frecuentes y mayor respiración visual.
- Elementos destacados solo cuando ayudan a recorrer el argumento.
- Imágenes con presencia editorial y pies accesibles.
- Ritmo variado sin convertir el libro en una revista promocional.

### Manual técnico o educativo

- Navegación fuerte, secuencias, advertencias, ejemplos y código diferenciados.
- Jerarquía funcional antes que decorativa.
- Tablas y procedimientos capaces de crecer sin romper la página.
- Encabezados que permitan ubicar módulo, capítulo o tema.

### Ensayo o libro humanístico

- Cuerpo de lectura estable y aperturas con identidad contenida.
- Menos niveles visibles y mayor continuidad de página.
- Citas extensas, notas y epígrafes tratados como parte del ritmo.
- Evitar recursos gráficos que fragmenten innecesariamente la lectura.

## Tipografía

- Elegir fuentes disponibles en los equipos donde se editará el documento. Una fuente incrustada o poco común puede sustituirse al abrir el DOCX.
- Usar una o dos familias salvo que exista una identidad editorial que justifique más.
- Asignar funciones, no adornos: cuerpo, títulos, datos, código y símbolos.
- Establecer tamaños y espaciados como sistema relativo. Una diferencia mínima entre niveles crea ambigüedad; una escala excesiva desperdicia página y dificulta futuras adiciones.
- Comprobar cursivas, negritas, versalitas, cifras, signos, caracteres españoles, griegos y matemáticos necesarios.
- No elegir una fuente por apariencia si carece de licencia o cobertura de caracteres adecuada.

## Página y retícula

Word no es una aplicación de composición de página fija. Diseñar una retícula que tolere reflujo:

- definir una caja de texto estable mediante márgenes y secciones;
- reservar margen interior suficiente cuando haya encuadernación;
- evitar columnas estrechas si existen ecuaciones, tablas o direcciones largas;
- mantener una escala vertical coherente mediante estilos y espaciados;
- usar blancos de apertura y separación con propiedades de párrafo, nunca con líneas vacías;
- probar páginas densas y ligeras antes de adoptar el formato.

## Color y contraste

- El color debe distinguir, orientar o establecer jerarquía; no compensar una estructura débil.
- Comprobar que la información siga siendo comprensible en escala de grises.
- Evitar texto de cuerpo con contraste bajo, fondos saturados y combinaciones que dependan solo del color.
- Aplicar el color mediante estilos o tema para poder sustituirlo de manera global.

## Aprobación de la dirección

Una muestra útil reúne casos reales, no páginas de demostración vacías. Incluir contenido difícil: el título más largo, una tabla ancha, una figura vertical, una cita extensa, notas o ecuaciones si existen. La aprobación debe cubrir el sistema, no una página aislada corregida manualmente.

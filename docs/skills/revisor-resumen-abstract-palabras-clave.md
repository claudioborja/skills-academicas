# Revisor Resumen Abstract Palabras Clave

Úsalo cuando el usuario necesite redactar, corregir u optimizar resumen, abstract, sinopsis, palabras clave, descriptores o texto de contraportada, manteniendo precisión conceptual, densidad informativa y naturalidad.

## Uso

Invócala directamente con `$revisor-resumen-abstract-palabras-clave` o permite que el orquestador la seleccione según el encargo.

Ejemplo:

```text
Usa $revisor-resumen-abstract-palabras-clave para [describe aquí la tarea y los archivos de entrada].
```

- Flujo de trabajo
- Validación final

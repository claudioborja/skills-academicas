El catálogo contiene 32 skills. Sus fichas se regeneran desde los recursos locales; los `SKILL.md` son las instrucciones normativas. El README principal y esta guía se mantienen manualmente. Para revisiones, Kitchenham y PRISMA son rutas separadas: Kitchenham gobierna su metodología en ingeniería de software; PRISMA gobierna el reporte y exige declarar aparte el método de conducción. Para contribuciones, CRediT describe tareas, mientras la política del destino gobierna la autoría y los esquemas técnicos gobiernan la exportación.

La reutilización de evidencia y la revisión integrada son reglas de trabajo. No implican que exista una implementación RAG/SQLite ni que se hayan demostrado ahorros de tokens o aceptación editorial.

# Mapa De Transformación Tesis A Libro

| Sección de tesis | Tratamiento editorial | Resultado en libro |
|---|---|---|
| Portada institucional | Reemplazar | Portada editorial |
| Dedicatoria | Opcional | Dedicatoria breve |
| Agradecimientos | Reducir | Agradecimientos editoriales |
| Resumen/abstract | Reescribir | Contraportada, sinopsis o presentación |
| Planteamiento del problema | Transformar | Introducción orientada al lector |
| Objetivo general | Transformar | Propósito del libro |
| Objetivos específicos | Redistribuir | Promesas o ejes de capítulos |
| Hipótesis | Reformular | Tesis argumental |
| Justificación | Reescribir | Relevancia social, académica o profesional |
| Marco teórico | Seleccionar | Capítulo conceptual o hilo distribuido |
| Estado del arte | Resumir | Contexto, antecedentes o debate |
| Metodología | Reducir o mover | Nota metodológica, apartado breve o anexo |
| Resultados | Convertir | Capítulos de hallazgos, casos o análisis |
| Discusión | Ampliar | Interpretación y aportes |
| Conclusiones | Reescribir | Cierre editorial, recomendaciones o agenda |
| Anexos | Filtrar | Recursos, instrumentos o material complementario |
| Bibliografía | Auditar | Bibliografía final consistente |

## Principio

Una tesis demuestra competencia investigativa ante una institución. Un libro guía a un lector hacia una comprensión, una práctica o una interpretación. La conversión debe cambiar la función del texto, no solo los títulos.

## Decisiones Frecuentes

- Si la metodología es central para la credibilidad, mantenerla resumida en el cuerpo.
- Si la metodología interrumpe la lectura, moverla a anexo.
- Si el marco teórico es largo, distribuirlo por capítulos.
- Si los resultados son muchos, agruparlos por pregunta editorial.
- Si las tablas son densas, convertir algunas en síntesis narrativas.

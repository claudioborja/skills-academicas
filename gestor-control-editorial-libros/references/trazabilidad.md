# Trazabilidad E Informe

## Estados

Usar únicamente:

- `CUMPLE`: existe evidencia comprobada;
- `NO_CUMPLE`: el criterio es aplicable y la evidencia confirma el incumplimiento;
- `N_A`: el criterio no corresponde al tipo de obra, con justificación;
- `NO_VERIFICABLE`: faltan datos o acceso para comprobarlo;
- `PENDIENTE_CONFIRMACION`: existe un dato plausible, pero requiere autoridad o confirmación.

## Registro Por Criterio

Cada fila o hallazgo debe incluir:

| Campo | Contenido |
| --- | --- |
| Etapa | Admisibilidad, front matter, BKCI o prepublicación. |
| Criterio | Requisito concreto y su origen. |
| Estado | Uno de los cinco estados autorizados. |
| Evidencia | Archivo, registro, página, URL, identificador o manifestación autorizada. |
| Explicación | Por qué la evidencia sostiene el estado. |
| Acción | Corrección, consulta o comprobación necesaria. |
| Responsable | Persona o función confirmada; no inferirla. |
| Fecha | Fecha de comprobación o de próxima revisión. |

## Reglas De Intervención

No corregir silenciosamente nombres, autoría, afiliaciones, ORCID, ISBN, DOI, licencia, financiación, conflictos, ética ni permisos. Separar el hallazgo de la propuesta y exigir autorización antes de modificar un documento fuente.

Cuando se apruebe una corrección, registrar el valor anterior, el valor confirmado, la fuente de autoridad, los archivos afectados y la reverificación. Propagar cambios a front matter, capítulos, OMP, registros DOI y entregables solo dentro del alcance autorizado.

El informe de control es un artefacto del expediente; no debe aparecer como capítulo, anexo visible o nota interna en el libro publicado salvo petición expresa.

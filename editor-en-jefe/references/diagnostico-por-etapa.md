# Diagnostico por etapa

- Si el usuario inicia un libro, determinar la etapa por su contenido y decisiones existentes. La ausencia de carpetas canónicas no implica falta de planificación; crear solo destinos necesarios según la estructura elegida.
- Si el usuario trae una tesis, tesina, disertacion o trabajo de grado para publicarlo como libro, esta en conversion tesis -> libro.
- Si el usuario habla de tema, alcance, indice o capitulos, esta en planificacion.
- Si habla de autores, antecedentes, debates o vacios, esta en marco teorico.
- Si trae borradores, esta en redaccion o reescritura.
- Si el texto existe pero no convence, esta en auditoria argumentativa.
- Si trae un documento modelo y pide replicar voz, conectores, expresiones o estilo, esta en perfilado de estilo antes de humanizacion.
- Si el texto esta correcto pero suena repetitivo, generico, mecanico o marcado como IA, esta en humanizacion/desgenericacion academica.
- Si hay citas textuales o transcripciones, deben protegerse antes de cualquier reescritura.
- Si el problema es forma final, esta en correccion o preentrega.
- Si el producto es un libro destinado a Word, verificar el DOCX editable y el respaldo TXT previsto en el perfil de entrega; no reducir la entrega a texto plano.
- Si trae observaciones externas, esta en fase de respuesta y ajuste.

# Mapa de responsabilidades

Elegir por el resultado solicitado. Las siguientes especialidades complementan al orquestador; no son una lista de ejecución obligatoria.

| Necesidad | Skill responsable | Frontera |
| --- | --- | --- |
| Arquitectura de libro y estructura de proyecto | `planificador-obra-academica` | No imponer carpetas de libro a artículos o revisiones. |
| Construir o revisar una tesis | `constructor-tesis-academica` | El producto sigue siendo tesis. |
| Transformar una tesis en libro | `convertidor-tesis-a-libro` | Cambia lector y género; conserva evidencia. |
| Explorar temas y literatura inicial | `explorador-temas-articulos` | El protocolo elegido gobierna las revisiones posteriores. |
| Revisión Kitchenham | `revision-sistematica-kitchenham` | Autoridad metodológica de su revisión; no importar PRISMA. |
| Marco teórico y debates | `gestor-marco-teorico-estado-del-arte` | Sintetizar y relacionar literatura, no listar resúmenes. |
| Artículo científico | `redaccion-articulo-cientifico-imryd` | Organizar el informe sin cambiar el diseño del estudio. |
| Redactar contenido | `gestor-redaccion-latinoamerica` | Construir prosa con evidencia disponible. |
| Naturalidad, desgenericación y voz | `humanizar-redaccion-academica` | No inventar contenido para parecer más humano. |
| Corrección final de lengua | `correccion-estilo-ortotipografica` | Evitar reescritura de fondo cuando solo se pide corregir. |
| Lógica del argumento | `auditor-coherencia-argumentativa` | Evaluación sustantiva, distinta del inventario mecánico. |
| Continuidad entre capítulos | `gestor-continuidad-libro` | Relación entre partes, voz y progresión de la obra. |
| Términos y glosario | `normalizador-terminologia-glosario` | Consistencia conceptual y denominaciones. |
| Convertir y segmentar archivos | `preprocesador-documentos` | Preparar lectura; no decidir calidad científica. |
| Inventario documental | `auditor-documental-academico` | Hallazgos mecánicos que requieren interpretación. |
| Señales de estructura IMRyD | `auditor-articulo-imryd` | No certifica alineación científica ni publicabilidad. |
| Operaciones bibliográficas repetibles | `automatizador-referencias` | Metadatos, cruces y duplicados; no decide admisión de estudios. |
| Buscar, verificar y citar en APA/IEEE | `gestor-referencias-academicas` | Protocolo y política seleccionada gobiernan fuentes. |
| Correspondencia final citas-bibliografía | `revisor-citas-consistencia-bibliografica` | Revisión editorial apoyada por automatización. |
| Restricciones bibliográficas adicionales | `ajustes-editoriales-bibliograficos` | Distinguir política del proyecto y norma de cita. |
| Riesgo de procedencia editorial | `filtro-editoriales-depredadoras` | Alertas justificadas; no usar ausencia de DOI como prueba de fraude. |
| Localizar o generar imágenes | `gestor-imagenes-academicas-libros` | Necesidad, origen, licencia y trazabilidad. |
| Tablas, figuras y pies | `gestor-tablas-figuras-pies` | Integración editorial, llamadas, numeración y notas. |
| Ecuaciones, símbolos y unidades | `gestor-ecuaciones-academicas` | Preservar significado, editabilidad, notación y referencias; no certifica por sí sola la validez del modelo. |
| Listados de código y salidas técnicas | `gestor-codigo-tecnico-editorial` | Presentación, trazabilidad y lectura editorial; no desarrolla ni valida el software. |
| Resumen y piezas breves | `revisor-resumen-abstract-palabras-clave` | Condensar el contenido real. |
| Formato y exportación final | `maquetacion-academica-preentrega` | Aplicar el perfil del proyecto y verificar el artefacto. |
| Observaciones de tutor o revisores | `respondedor-observaciones-academicas` | Vincular respuesta, decisión y cambio trazable. |

# Roles CRediT

CRediT es el núcleo recomendado para describir contribuciones a salidas de investigación. Sus 14 términos canónicos son:

| Término canónico | Uso práctico |
| --- | --- |
| Conceptualization | Ideas, objetivos y formulación general de la investigación. |
| Data curation | Anotación, limpieza, documentación, mantenimiento y reutilización de datos. |
| Formal analysis | Técnicas estadísticas, matemáticas, computacionales u otros análisis formales. |
| Funding acquisition | Obtención del apoyo financiero que condujo a la obra. |
| Investigation | Ejecución de experimentos o recopilación de datos y evidencia. |
| Methodology | Diseño o desarrollo de métodos, modelos y procedimientos. |
| Project administration | Coordinación y gestión de la planificación y ejecución. |
| Resources | Provisión de materiales, muestras, instrumentos, infraestructura u otros recursos. |
| Software | Programación, desarrollo, implementación y pruebas de componentes de software. |
| Supervision | Dirección, liderazgo y mentoría de la actividad investigadora. |
| Validation | Verificación de resultados, experimentos y reproducibilidad. |
| Visualization | Preparación y presentación visual de datos o resultados. |
| Writing – original draft | Preparación sustantiva del borrador inicial. |
| Writing – review & editing | Revisión crítica, comentario y edición sustantiva del trabajo. |

## Reglas de asignación

- Registrar tareas realizadas, no cargos ni expectativas.
- Una persona puede tener varios roles; un rol puede tener varias personas.
- Omitir los roles que no correspondan.
- Si se usa grado de contribución (`lead`, `equal`, `supporting`), identificarlo como extensión solicitada por el destino, no como parte intrínseca de CRediT.
- No usar el número de roles para medir importancia ni decidir orden de firma.
- `Funding acquisition`, `Supervision` o `Project administration` por sí solos no garantizan autoría bajo criterios como ICMJE.
- La traducción sustantiva puede entrar en `Writing – original draft` según CRediT; la traducción bibliográfica también puede requerir el relator MARC `translator`.

Usar siempre los términos canónicos en los metadatos; las traducciones pueden presentarse al lector sin reemplazar su identificador estable.

# Coordinación Con Skills Auxiliares

## Regla

Kitchenham gobierna el método. Activar otras skills solo por necesidad técnica o editorial. No importar criterios metodológicos incompatibles.

| Fase Kitchenham | Skill auxiliar | Uso permitido | Límite |
| --- | --- | --- | --- |
| Insumos largos | `$preprocesador-documentos` | Convertir PDF/DOCX, segmentar y proteger | No sustituye lectura crítica |
| Alcance inicial | `$explorador-temas-articulos` | Clasificar, detectar vocabulario y tabular | No usar protocolo, selector ni conteos PRISMA |
| Metadatos | `$automatizador-referencias` | Inventariar DOI, fuentes y duplicados | No decidir inclusión |
| Riesgo editorial | `$filtro-editoriales-depredadoras` | Detectar sitios clonados y riesgo | No excluir solo por ausencia de DOI si el protocolo no lo exige |
| Bibliografía | `$gestor-referencias-academicas` | Formatear citas verificadas | No reemplazar criterios Kitchenham |
| Consistencia | `$revisor-citas-consistencia-bibliografica` | Cruzar citas y referencias | No agregar fuentes no incluidas |
| Informe | `$redaccion-articulo-cientifico-imryd` | Organizar si la revista exige IMRyD | No cambiar el método |
| Auditoría | `$auditor-articulo-imryd` | Revisar alineación del manuscrito | Aplicar después de sintetizar |
| Visuales | `$gestor-tablas-figuras-pies` | Uniformar tablas y gráficos | Preservar datos |
| Resumen | `$revisor-resumen-abstract-palabras-clave` | Redactar al finalizar | No anticipar resultados |
| Lógica | `$auditor-coherencia-argumentativa` | Auditar pregunta-evidencia-conclusión | No reescribir datos |
| Estilo | `$correccion-estilo-ortotipografica` | Corrección final | Ejecutar al cierre |
| Naturalidad | `$humanizar-redaccion-academica` | Mejorar prosa propia | Proteger citas y resultados |
| Entrega | `$maquetacion-academica-preentrega` | Limpieza formal | No adelantar |
| Revisores | `$respondedor-observaciones-academicas` | Matriz de respuestas | Conservar trazabilidad |

## Secuencia

1. Kitchenham crea plan y protocolo.
2. Skills técnicas aportan insumos mecánicos.
3. Kitchenham gobierna búsqueda, selección, calidad, extracción y síntesis.
4. Skills editoriales preparan y auditan el informe.
5. Skills de estilo cierran el producto.

Ante un conflicto, conservar la función técnica útil, rechazar la regla incompatible, aplicar el protocolo y documentar la decisión.
